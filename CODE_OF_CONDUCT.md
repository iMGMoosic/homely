# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, be patient, assume good intent, and keep discussions about the work.
Harassment, personal attacks, and discriminatory language are not tolerated.

To report a problem, open an issue marked "conduct" or email the maintainer listed on the
GitHub profile. Reports are handled confidentially.
